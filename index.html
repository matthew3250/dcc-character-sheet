DCC Character Sheet — Version Info

Sheet Version Information

Version: v2.1.0

Changelog:

  • v2.1.0:
    1. The skill list now print in a table format.
    2. The Skill notes are printed at the end of the document.
    3. Attributes now add Base + Enhacements.
  • v2.0.0:
    1. Updated UI for mobile devices with responsive card views and custom drawer navigation.
    2. Restored red X buttons for Attacks/Skills with mobile corner-positioning.
    3. Restored textarea skill notes with desktop toggle & mobile editor modal.
  • v1.2.0:
    1. New Pets tab for tracking our critters!
    2. Added Deity box in the Race/Class section to track information about who you worship.
    3. Fixed Printing so the page looks a bit cleaner for printing.
    4. Added Version Display
  • v1.1.0:
    1. Updated Skills so Notes is a text area that can be hidden/expanded as needed.
    2. Hot List is now only 10 to match the Core-Rules.
  • v1.0.0:
    1. Added Health Bar over Heal %.
    2. Added Current and Max Mana Section.
    3. Corrected multiple spelling errors.
    4. Added "Save As" support for Edge, Chrome, Firefox for easier Character Management.
    Note: If you have saved a sheet from v0.0.0, you will need to update your JSON to change the element name of "bio_religous" to "bio_religious".
  • v0.0.0: Draft, Built based upon released Character PDF.
